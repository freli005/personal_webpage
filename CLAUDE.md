# Personal webpage (Jekyll / Beautiful Jekyll fork)

Static academic site, deployed to Netlify from `master`. Build and serve locally with
`bundle exec jekyll serve --livereload` (see README.md for setup).

## Conventions

- **team.md**: both the current-team list and the alumni list are ordered by start date,
  newest on top. Add new members at the top of the relevant list.
- Publications are generated by jekyll-scholar from `_bibliography/lindsten.bib`; only
  entries with a `pid` field (J*, C*, M*, B*, ...) are shown on the publications page.
